## Required mixed-version restriction

Keep `NORN_FLEET_CREATE_ENABLED=false` throughout this proposed mixed-version
window. `registerEtcdFleetCreateRoutes` requires both the executor lane and this
flag. It defaults to false.

The candidate adds `/v3/fleet-create-fences/` records and teaches
`fleetTargetInFlightCompares` to read and compare that prefix before registering
a target. The baseline does not know that fence. Thus unchanged record types do
not imply equivalent mutation exclusion: enabling fresh creation while an old
writer remains could let that writer miss a new create reservation. New create
routes must remain unavailable until old writers are retired, including the
rollback window. If fresh-create records already exist, a separate readback and
compatibility decision is required; the flag alone does not erase them.
